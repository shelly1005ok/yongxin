# Yongxin Canada ASTM A270 landing page

Static HTML landing page for the Canada ASTM A270 sanitary-tube campaign. It has no build step and can be published directly through GitHub Pages. The blue Canadian hero visual is at `assets/canada-astm-a270-hero.png`; replace that file (or update its path in `styles.css`) when production photography is ready.

## GitHub Pages

1. Create a GitHub repository and upload the contents of this folder, including `assets/`.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, and select the repository root (`/`).
4. GitHub will provide the public page URL after deployment.

## Before publishing

1. Connect the form in `script.js` to the company's approved email or CRM endpoint. It currently validates inputs only and does not transmit enquiry data.
2. Add the approved privacy-policy link before running ads.
3. Keep the ASTM A270 / AS 1528.1 availability table and the 3-A dimensional table separate; they represent different catalogue information.
4. If certificate images or logos are added, publish their applicable product scope and validity details alongside them.
