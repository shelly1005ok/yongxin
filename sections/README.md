# Landing-page modules

The files prefixed `01` through `08` are the editable source modules for the current Canada ASTM A270 landing page. They are intended to be combined in number order into one final HTML document.

1. Start a final document with the `<head>` from `../index.html` and its opening `<body>`.
2. Paste `01-header-hero.html` through `08-footer.html` in order.
3. Keep `../styles.css`, `../script.js`, and `../assets/` next to the final document so the relative paths work.

The unprefixed files are older independent design previews and are retained as optional references only.
